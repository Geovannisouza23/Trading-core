# Internal event contracts

This registers the outbox event envelope and every event type currently
published on it — the payload contract `internal/infrastructure/database
/outbox/publisher.go` decodes and `internal/interfaces/consumer/outbox`
forwards to the dashboard WebSocket. See `docs/decisions/0004-transactional
-outbox.md` for why these specific events are outbox-durable while
`SignalCreated`/`RiskDecisionCreated` are not.

## Envelope (as persisted in `outbox_events`)

| Column | Type | Notes |
|---|---|---|
| `id` | UUID | Generated by the producing use case. |
| `event_type` | text | One of the names below — the discriminator `publisher.go`'s `decode` switches on. |
| `payload` | jsonb | The Go event struct, `encoding/json`-marshaled directly (every domain value object implements `MarshalJSON`/`UnmarshalJSON`, so this always round-trips losslessly). |
| `status` | text | `PENDING` → `PROCESSING` → `PROCESSED` \| `FAILED`. |
| `attempts` | int | Incremented by `MarkFailed`; moves to `FAILED` at 5. |
| `created_at` | timestamptz | |

## Versioning policy

There is no `v2` yet. When a payload shape needs to change in a
backward-incompatible way, add a new `event_type` string (e.g.
`OrderFilled.v2`) rather than mutating the meaning of an existing one —
`publisher.go`'s `decode` switch is the single place that would need a new
`case`, and old rows already sitting in `outbox_events` (however unlikely,
given the worker drains them promptly) stay decodable under their original
type.
